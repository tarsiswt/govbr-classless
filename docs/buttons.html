Botões

O elemento <button> renderiza automaticamente como botão primário (azul sólido, pill shape). Variantes de cor usam o atributo data-variant — sem nenhuma classe CSS.

Botão primário

Azul #1351b4, borda-raio pill, peso 600. Use para a ação principal da tela.

Botão secundário — data-variant="secondary"

Contorno azul, fundo transparente. Use para ações alternativas menos importantes.

Botão terciário — data-variant="tertiary"

Sem fundo e sem borda visível. Use para ações de baixa prioridade.

Variantes semânticas

Use data-variant com danger, success ou warning.

Estado desabilitado

O atributo disabled aplica opacidade 0,5 e remove interatividade.

Link como botão — role="button"

Use <a role="button"> quando o destino é uma URL mas o visual deve ser de botão. Combine com data-variant.
