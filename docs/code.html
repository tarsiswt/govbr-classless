Código

Elementos semânticos para exibição de código, atalhos de teclado e saídas de sistema. Todos usam fonte monospace com fundo discreto para destacar do texto corrido.

Código em linha — <code>

Use para nomes de variáveis, propriedades CSS, comandos curtos e valores técnicos.

Atalhos de teclado — <kbd>

Use para representar teclas ou combinações de teclas.

Saída de sistema — <samp>

Use para representar saída de programas ou terminais.

Variável — <var>

Use para nomes de variáveis matemáticas ou de programação em contexto de texto.

Bloco de código — <pre><code>

Use para exemplos de código multilinhas. Fundo escuro para alto contraste. Borda esquerda azul indica trecho de código. Scroll horizontal automático para linhas longas.
