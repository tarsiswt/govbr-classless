Dialog / Modal

O elemento nativo <dialog> com .showModal() cria um modal com backdrop automático. Sem JavaScript externo, sem biblioteca. O CSS aplica bordas arredondadas, sombra e o backdrop azul escuro semitransparente.

Dialog de confirmação

Abra com dialogElement.showModal(). Feche com .close().

Dialog com formulário

Fechar ao clicar fora

O comportamento padrão do <dialog> não fecha ao clicar no backdrop. Este snippet mostra como adicionar esse comportamento com JavaScript mínimo: 

const dialog = document.getElementById('meu-dialog');
dialog.addEventListener('click', e => {
  if (e.target === dialog) dialog.close();
});
