Layout

O GovBR Classless estiliza os elementos semânticos de layout do HTML5 diretamente. Uma página completa é composta por <header>, <nav>, <main> e <footer> — sem nenhuma classe.

Estrutura de uma página completa

<body>

  <!-- Link de acessibilidade: pular para o conteúdo -->
  <a href="#main">Pular para o conteúdo</a>

  <!-- Cabeçalho: azul #1351b4, sticky, sombra -->
  <header>
    <h1>Nome do Sistema</h1>
    <!-- nav dentro do header: transparente e embutido -->
    <nav>
      <ul>
        <li><a href="/">Início</a></li>
        <li><a href="/servicos">Serviços</a></li>
      </ul>
    </nav>
  </header>

  <!-- nav avulso: fundo azul escuro #0c326f, abaixo do header -->
  <nav>
    <ul>
      <li><a href="#">Categoria A</a></li>
    </ul>
  </nav>

  <!-- main: flex:1, max-width 1200px, centrado, fundo branco -->
  <main id="main">
    <h2>Conteúdo principal</h2>
    <p>...</p>
  </main>

  <!-- footer: fundo #071d41, sticky no rodapé -->
  <footer>
    <p>&copy; 2026 Governo Federal</p>
  </footer>

</body>

Rodapé fixo no fundo

O <body> usa display: flex; flex-direction: column; min-height: 100vh e o <main> recebe flex: 1. O rodapé fica sempre no fundo, independente do volume de conteúdo.

Layout de duas colunas (artigo + sidebar)

Quando <main> contém um <article> e um <aside> como filhos diretos, o CSS aplica grid-template-columns: 1fr 280px automaticamente via :has() — sem nenhuma classe adicional. 

<main>
  <article>
    <!-- conteúdo principal -->
  </article>

  <aside>
    <!-- sidebar automática: fundo azul pastel, borda esquerda azul -->
  </aside>
</main>

Veja o exemplo completo em examples/page-with-sidebar.html.

Article e Aside

<article>: representa conteúdo autocontido — um artigo, publicação, ficha de serviço. <aside>: sidebar de conteúdo relacionado — links úteis, metadados, navegação secundária.

Um <header> dentro de <article> ou <section> tem seus estilos redefinidos automaticamente: fundo transparente, posição estática, cor de texto normal.

Padrões de navegação

Nav dentro do header — lista horizontal alinhada ao cabeçalho azul, mesclada ao header: 

<header>
  <h1>Portal</h1>
  <nav>
    <ul>
      <li><a href="#">Início</a></li>
    </ul>
  </nav>
</header>

Nav avulso — barra de navegação secundária com fundo azul escuro (#0c326f): 

<nav aria-label="Menu secundário">
  <ul>
    <li><a href="#">Categoria A</a></li>
    <li><a href="#">Categoria B</a></li>
  </ul>
</nav>

Nome Largura mínima Token Comportamento

sm/md (tablet) 576–992px --breakpoint-md: 992px Sidebar 240px, headings menores
lg (desktop) 1280px --breakpoint-lg: 1280px Grid completo, sidebar 280px
xl (TV/wide) 1600px --breakpoint-xl: 1600px Max-width 1200px centrado
