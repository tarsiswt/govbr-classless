Mídia

Imagens e figuras são responsivas por padrão (max-width: 100%), com bordas arredondadas. O <figcaption> recebe estilo automaticamente: itálico, menor e centralizado.

Imagem simples

Use sempre alt descritivo para acessibilidade. A imagem nunca ultrapassa a largura do contêiner pai.

Figura com legenda — <figure> + <figcaption>

Galeria de figuras

SVG em linha

SVGs recebem max-width: 100% e display: block automaticamente.

Boas práticas de acessibilidade

  • Sempre forneça alt descritivo. Use alt="" para imagens decorativas.
  • Para SVGs significativos, use role="img" e aria-label ou <title> + <desc>.
  • Prefira <figure> + <figcaption> quando a imagem precisar de contexto explicativo.
  • Especifique width e height para evitar layout shift (CLS) durante o carregamento.
