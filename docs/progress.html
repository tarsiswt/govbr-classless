Progresso e Medidor

Os elementos nativos <progress> e <meter> são estilizados com as cores e tokens do GovBR-DS, sem nenhuma classe ou biblioteca adicional.

Barra de progresso — <progress>

Use value e max para definir o percentual. A barra preenche em azul gov.br sobre fundo cinza.

Progresso indeterminado

Omita o atributo value para a animação de carregamento do navegador.

Progresso interativo

Medidor — <meter>

Use min, max, low, high e optimum para definir o intervalo e o nível ideal. O navegador aplica cores semânticas (verde, amarelo, vermelho) baseadas nesses atributos.
