Design Tokens

Todos os tokens são CSS custom properties (--nome-do-token) definidas no :root. Os tokens de paleta vêm do @govbr-ds/core@3.7.0 via CDN e os tokens semânticos (que mapeiam a paleta a significados) são definidos no próprio govbr-classless.css.
