Tipografia

A escala tipográfica é ancorada em 14px (87,5% do padrão de 16px do navegador). A fonte principal é Rawline com fallback para Raleway. Todas as unidades são rem, relativas à raiz de 14px.

Títulos (h1–h6)

Escala de 3rem (42px) a 1rem (14px). Nenhuma classe necessária.

Parágrafo

Line-height alto (1,85) para máxima legibilidade. Largura máxima de 72 caracteres automaticamente.

Links

Cor padrão: azul #1351b4. Visitado: roxo. Foco: anel pontilhado vermelho (padrão GovBR-DS). Hover: azul mais escuro + espessura da linha.
