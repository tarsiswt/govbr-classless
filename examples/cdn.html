Usar via CDN

Inclua uma única linha no <head> do seu HTML. Nenhum pacote para instalar, nenhuma dependência, nenhum passo de build. 

<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/gh/tarsiswt/govbr-classless@main/dist/govbr-classless.min.css">

Servido pelo jsDelivr CDN — gratuito, sem limite de banda, com cache global. O arquivo é atualizado automaticamente a cada push para a branch main.

Boilerplate mínimo

Copie, cole, escreva HTML semântico. Já está estilizado.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Minha página</title>
  <link rel="stylesheet"
    href="https://cdn.jsdelivr.net/gh/tarsiswt/govbr-classless@main/dist/govbr-classless.min.css">
</head>
<body>

  <header>
    <h1>Nome do sistema</h1>
    <nav>
      <ul>
        <li><a href="/">Início</a></li>
        <li><a href="/sobre">Sobre</a></li>
      </ul>
    </nav>
  </header>

  <main>
    <h2>Bem-vindo</h2>
    <p>Conteúdo da página.</p>

    <button>Ação principal</button>
    <button data-variant="secondary">Cancelar</button>
  </main>

  <footer>
    <p>GovBR Classless — Padrão Digital de Governo</p>
  </footer>

</body>
</html>

Resultado ao vivo

Esta própria página é carregada exclusivamente via CDN — sem arquivos locais, sem site.css.

O que é o GovBR Classless?

Um framework CSS sem classes baseado no Padrão Digital de Governo 3.7.0. Escreva HTML semântico puro e obtenha o visual do gov.br automaticamente.

Preciso instalar algo?

Não. Um único <link> no <head> é suficiente.

Posso usar junto com outros frameworks?

Sim, desde que os estilos não entrem em conflito. O GovBR Classless estiliza apenas elementos HTML nativos e algumas classes explícitas como .avatar.
