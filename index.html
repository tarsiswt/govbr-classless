Documentação de componentes

Framework CSS classless baseado no Padrão Digital de Governo 3.7.0. Inclua um único arquivo CSS e escreva HTML semântico puro. 

<link rel="stylesheet" href="govbr-classless.css">

v0.1.0 GovBR-DS 3.7.0 Zero dependências

Componentes

Tipografia

Headings, parágrafos, links, citações, inline elements

Código

code, pre, kbd, samp, var — blocos e em linha

Listas

ul, ol, aninhadas, dl — glossários e metadados

Tabelas

thead azul, linhas alternadas, hover, caption, tfoot

Formulários

Todos os tipos de input, select, textarea, fieldset, validação

Botões

Primário, secundário, terciário, danger, success — via data-variant

Acordeão

details + summary nativo — FAQ, conteúdo expansível

Dialog / Modal

dialog nativo com backdrop, confirmação, formulários

Progresso

progress determinado e indeterminado, meter com níveis

Mídia

img responsiva, figure + figcaption, SVG

Layout

header, nav, main, aside, article, footer — estrutura de página

Design Tokens

Paleta de cores, tipografia, espaçamento, sombras, foco
