Pico CSS × GovBR-DS

Exploração de tema: Pico CSS v2 customizado com tokens do Padrão Digital de Governo 3.7.0

Esta página carrega apenas dois arquivos CSS: o Pico CSS classless (CDN) e o tema GovBR-DS que sobrescreve suas variáveis --pico-*. Nenhum build step, nenhum Sass, nenhum JavaScript.

Como usar 
<!-- 1. Pico CSS classless -->
<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@picocss/pico@2/css/pico.classless.min.css">

<!-- 2. Tema GovBR-DS -->
<link rel="stylesheet" href="govbr-pico-theme.css">

Acordeão (details/summary)

O que é o Padrão Digital de Governo?

É o conjunto de padrões, diretrizes e boas práticas que orientam o design de interfaces e serviços digitais do Governo Federal brasileiro. Inclui guia de estilo, componentes, tokens de design e acessibilidade.

Como faço para usar o GovBR-DS?

Você pode usar o framework classless (um único <link>) ou os web components da biblioteca @govbr-ds/webcomponents. Para sistemas legados, o pacote @govbr-ds/core fornece classes CSS.

Quais são os requisitos de acessibilidade?

O PDG segue a WCAG 2.1 nível AA, o eMAG (Modelo de Acessibilidade em Governo Eletrônico) e a Lei Brasileira de Inclusão (LBI). Contraste mínimo 4.5:1 para texto e foco visível em todos os elementos interativos.

Conclusão preliminar

Pontos de alinhamento e divergência

O Pico CSS cobre bem tipografia, formulários, tabelas, modal e acordeão — os componentes com base em HTML semântico nativo. O tema GovBR consegue alinhar cores, tipografia (Rawline), foco tracejado vermelho e a paleta azul navy do header.

Lacunas: Pico não tem tabs, avatares, breadcrumb, nem o padrão de botão com data-variant. O dark mode do Pico é mais rico que o do GovBR-DS (que não define dark mode oficialmente), o que é um bônus. A dependência no upstream do Pico é o principal risco: mudanças de variáveis em versões futuras podem quebrar o tema silenciosamente.
