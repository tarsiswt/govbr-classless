GovBR-DS Web Components v1.21.3

Componentes customizados do Padrão Digital de Governo usados junto ao framework classless. Inclua o script UMD e escreva elementos <br-*> diretamente no HTML — sem frameworks, sem build tools. 

<script src="https://cdn.jsdelivr.net/npm/@govbr-ds/webcomponents@1.21.3/dist/webcomponents.umd.min.js"></script>

Comparação: Web Component × HTML semântico

Os Web Components encapsulam markup e estilo em Shadow DOM. O classless framework estiliza elementos HTML nativos diretamente. Ambas as abordagens produzem resultados visuais próximos — escolha a que melhor se encaixa no seu fluxo de trabalho.

Por que usar Web Components?
  • Encapsulamento total: estilos ficam no Shadow DOM, sem vazamento para a página.
  • Comportamento embutido: select com busca, loading states, modais e tabs sem JS extra.
  • Consistência garantida: renderização idêntica ao Design System oficial.
Por que usar HTML semântico + classless CSS?
  • Zero dependências em runtime: sem script extra, sem bundle de 1 MB.
  • Acessível por padrão: elementos nativos já têm semântica e comportamento do browser.
  • Dark mode e tokens automáticos: herdam variáveis CSS do framework sem configuração.
